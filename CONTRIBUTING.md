# Contributing to MarkCraft

Thank you for helping improve MarkCraft. Please open an issue before starting a substantial change so the scope and direction can be agreed on.

## Development

```bash
pnpm install
pnpm run build
```

Keep pull requests focused, explain user-visible behavior, and include validation results. Do not include private documents, credentials, or generated local state.

## Commits

Use concise, action-oriented commit messages. Keep unrelated refactors out of feature or bug-fix pull requests.

## Reporting security issues

Please do not disclose security vulnerabilities in public issues. Follow [SECURITY.md](SECURITY.md).
